# Contributing to Anchor

Thank you for being interested in Anchor.

## Code contributions are not open yet

Anchor is not taking code contributions at the moment. The contributor
agreement that would cover them is still a draft and has not been reviewed,
and contributions should not be accepted without it. Pull requests will be
closed without being merged until that changes. This file will be replaced
when it does.

Bug reports, questions and ideas are welcome in the issue tracker.

## What to leave out of anything you post

Please do not post:

- Real journals, health information or other personal records.
- Credentials, keys or tokens.
- Other people's private data.

Use made-up examples for bug reports and demonstrations.

## Security issues

Please do not post exploitable security problems in a public issue. There is
no private security contact yet, so until there is one, open an issue that
says only that you have found a security problem, and leave out the details.

## Third-party material

Anything Anchor uses that someone else made is listed, with its licence, in
`THIRD-PARTY-NOTICES.md`.
