# Reference screenshots

Pictures of the real app in demo mode, recorded by `scripts/save-reference-shots.sh`. They are only here so the website's rebuild
of each screen (website/src/components/ios) can be compared against the app. Nothing in this folder is shipped on the website.

Each screen has `<name>.jpg` (660 pixels wide) and `<name>.json` (the buttons on that screen, with labels and positions).
The names are the table in `iOS/Anchor/AnchorUITests/DemoCaptureTests.swift`.
